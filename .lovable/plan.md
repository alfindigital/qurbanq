

# Aplikasi Qurban Lengkap

## Desain
- Tampilan formal & profesional dengan warna hijau tua (#1B5E20) dan emas (#C79B1B) sebagai aksen islami
- Layout sidebar navigasi dengan konten utama di kanan
- Font clean, spacing rapi, card-based UI

## Halaman & Fitur

### 1. Dashboard / Beranda
- Sambutan dan countdown menuju Hari Raya Qurban (Idul Adha)
- Ringkasan harga hewan qurban terkini
- Quick links ke fitur utama

### 2. Kalkulator Qurban
- Pilih jenis hewan (Sapi, Kambing/Domba, Unta)
- Pilih kualitas/berat hewan
- Hitung biaya per orang (sapi max 7 orang, kambing 1 orang)
- Hasil perhitungan + tombol "Pesan via WhatsApp" yang mengarah ke WA 089619093961 dengan pesan otomatis berisi detail pesanan

### 3. Simulasi Tabungan Qurban
- Input target hewan qurban & harga
- Input jangka waktu menabung (berapa bulan)
- Hitung jumlah tabungan per bulan/minggu
- Progress bar visual menunjukkan target vs tabungan

### 4. Edukasi Qurban
- Artikel: Hukum & syarat qurban, tata cara penyembelihan, pembagian daging, keutamaan berqurban
- FAQ seputar qurban
- Di akhir setiap artikel, ada CTA halus "Siap berqurban? Hubungi kami" → link WA

### 5. Reminder / Pengingat
- Countdown timer menuju Idul Adha
- Checklist persiapan qurban

## Promosi WhatsApp (Tersirat)
- Tombol "Konsultasi Qurban" floating di pojok kanan bawah → buka WA ke 089619093961
- Setelah kalkulasi, muncul CTA: "Dapatkan penawaran terbaik" → WA
- Di halaman edukasi, sisipan: "Butuh bantuan memilih hewan qurban?" → WA
- Pesan WA otomatis berisi detail hewan & harga yang dipilih user

## Navigasi
- Sidebar dengan menu: Beranda, Kalkulator, Tabungan, Edukasi, Pengingat
- Floating WhatsApp button di semua halaman
