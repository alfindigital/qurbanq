# Security Policy

## Scope

**Qurbanku** adalah SPA statis tanpa backend aktif. Tidak ada server, database, atau autentikasi pengguna. Data hanya tersimpan di `localStorage` perangkat kamu.

## Melaporkan Vulnerability

Buat [GitHub Security Advisory](https://github.com/alfindigital/qurbanq/security/advisories/new) (private) — jangan buat issue publik.

Sertakan: deskripsi, langkah reproduksi, estimasi dampak. Respons dalam **7 hari kerja**.
